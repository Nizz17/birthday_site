SAMRIDDHI BIRTHDAY WEBSITE — FRESH VERSION

Run locally:
  pip install flask
  python app.py
Open http://127.0.0.1:7860

Google Colab: upload this ZIP in the first setup cell, extract it, run app.py, then start ngrok. The site listens on port 7860.

CUSTOMIZE ASSETS:
- Replace static/assets/snoopy_cake.png with your preferred Snoopy-with-cake transparent cutout.
- static/assets/bouquet_character.png is the character you just supplied.
- Replace the photo-placeholder block in templates/index.html with your own photo when ready.
- Put your song at static/media/song.mp3 and edit the lyricLines array in static/script.js to add timestamped lyric snippets.
- Put your video at static/media/video.mp4.
- Edit the letter text in templates/letter.html.

No song, video, friend photo, or personal letter was supplied with this request, so the project includes clean editable placeholders instead of inventing personal content. The opening cake asset is currently the Snoopy image available from the supplied assets; replace it if it is not the exact cutout you want.
